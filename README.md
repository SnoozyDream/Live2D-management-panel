# Live2D Asset Management Panel (Portfolio)

Live2Dモデルアセットとユーザー権限を管理するためのWebベース管理画面のプロトタイプです。

## プロジェクト概要
所属ライバーのLive2Dモデル（.moc3）やテクスチャ、モーションデータを一括管理し、ブラウザ上でプレビュー・更新を行うためのシステムを想定しています。 
現在は、**Firebase (Firestore)** をバックエンドに採用し、クラウド上のデータとフロントエンドをリアルタイムに同期する動的な管理基盤を構築しています。

## 🛠️ 最新のアップデート (2026/02/10)
### **Firebase Firestore 連携によるデータ管理の動態化**
- **リアルタイム・データバインディングの実装**
  - ライバー情報と衣装（Outfits）情報をクラウドDBから取得し、動的にUIへ反映。
  - `async/await` および `for...of` ループを用いた非同期データ取得により、複数のコレクションを横断してデータを結合（JOIN）するロジックを実装。
- **データスキーマの最適化**
  - ライバー名（`liverName`）をキーとしたフィルタリング処理により、特定のライバーに紐づく所有衣装のみを抽出して表示するリレーション機能を実装。
- **堅牢なエラーハンドリング**
  - `try-catch` ブロックの導入により、ネットワーク遅延やデータ構造の不一致が発生した際も、システムがクラッシュせずユーザーに適切なフィードバックを返す仕様へ強化。

## 🛠️ 実装済み機能
- **Live2D Cubism SDK 統合 (v5.0対応)**
  - `Cubism Core` および `PixiJS` を利用した .moc3 モデルのレンダリング。
- **衣装管理システム（UUID導入）**
  - IDベースの管理により、同名衣装の重複問題を解消。
- **マルチページUI構築**
  - ダッシュボード / 衣装権限管理 / アセット登録 の画面遷移。
- **レスポンスUI設計**
  - PC・タブレット・モバイルに最適化されたグリッドレイアウト。

## 📂 アーキテクチャ構成
3-Layer アーキテクチャをベースに、クラウド連携層を統合しています。
- **Firebase / Firestore (Data Layer)**: クラウド上でのデータ永続化。
- **permissions.js / assets.js (Controller Layer)**: Firestoreからのデータ取得、フィルタリング、UIへの流し込みを制御。
- **live2d-viewer.js (Presentation Layer)**: WebGL/PIXI.jsを用いた高精度な描画エンジン。
